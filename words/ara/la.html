❤️ كَلَامُ الْمَحَبَّةِ ۝١

۝١ ιες γει λα: ιες λα βενφιε'νω,
۝٢ ιες λα γε'νω κεν ιες λα βεϋ'νω.
۝٣ λα βενφιε'νω σε χαι να τεκ γε'ε
۝٤ υκ βενφιε να δα μιωϋ λε κεν δα λη
۝٥ νοι. λα βενφιε'νω μυς γϋεν ιες νιεκ
۝٦ ιεν γε υκ βενφιε λη'κα φοκ νεκ.
۝٧ νοιφεκ μυς μαι κεν δαι λα γε'νω να τεκ
۝٨ γε εκ φεκ, νοιγε κεν φοκγε,
۝٩ νιειγε κεν μεκγε. λα βεϋ'νω νοιφεκ
۝١٠ μυς δαι να ιεν γε πον τεκ βεν, βιει
۝١١ ιενλη'νια τε'νω σε σος χεϋ νοιφεκ μοκ
۝١٢ νϋεν δα'εν μον γε ω'νω πο δα νοιφεκ
۝١٣ λη τε μον σος.

❤️ كَلَامُ الْمَحَبَّةِ ۝٢

۝١ λαγε σε γε χεϋ λα κεν λα'ας.
۝٢ λαγε νοιφεκνω σε χεϋ λα νοιφεκ κεν να
۝٣ νοιφεκ λα'ας.

❤️ كَلَامُ الْمَحَبَّةِ ۝٣

۝١ κοι κεϋ κιε χαι δα φοκλη να σος,
۝٢ ο-νοιλη ιαϋ; κεϋ βοιγε κεικα
۝٣ σος, ο-τος νιε λιε, καν ο-κας
۝٤ να λιε χεϋ ιεκ δα νιετελη τε;
۝٥ κεϋ σος μα σος χεϋ κιε χαι, ο-βιαϋ
۝٦ τε νιε να λιε, καν ο-φενλη κεν
۝٧ μως οϋ χεϋ ιεκ δα σάνοιλη κεν λιει
۝٨ λιε.

❤️ كَلَامُ الْمَحَبَّةِ ۝٤

۝١ και ιεν γε λα νιε φεν να γε δα'νω
۝٢ καν φαν λιε'νω, τε νιεσε λα,
۝٣ βιει λα βεϋ'νω νεκλαι γε χϋοι κεν γε
۝٤ χϋοι σε φεν υκ φαν.

❤️ كَلَامُ الْمَحَبَّةِ ۝٥

۝١ δα βεϋλη σε δα κας: «μιε χαι
۝٢ δα ιενλη φεν'ε κεν φαν'ε»,
۝٣ κεν δα βεν'εν σε δα ιενλη φεν'ε
۝٤ κεν φαν'ε.

❤️ كَلَامُ الْمَحَبَّةِ ۝٦

۝١ να βεν'εντο, ο-φαιλη νιε να
۝٢ χαι'ε φαννω κιε'νω, καν φαιλη
۝٣ να χαι'ε φαννω να λαγε κεν λϋω
۝٤ να λιε λα νιεφαννω.

❤️ كَلَامُ الْمَحَبَّةِ ۝٧

۝١ ο-λα κιε, ο-λα τεκ γε ω'νω
۝٢ εκ φεκ, κεν ο-λα νιεγε'ε.
۝٣ να δα λα κιε, ο-σε νοιγε να
۝٤ κιε; ο-γαλη πο τεκ λη νεκ;
۝٥ ο-ληλη πο τεκ λη βοι; ο-δαι
۝٦ να κιε τια δοϋ δα γιωλη; ο-λϋω
۝٧ λα να γε'ε ω'νω, βιει δα δαι
۝٨ νοι σε δα δος νοι κεν σα φας φοκ.

❤️ كَلَامُ الْمَحَبَّةِ ۝٨

۝١ ο-μει νϋεν κιει'ε να λα ρην δα κιε
۝٢ δος λα; ο-μει νϋεν κιει'ε να ρϋαι
۝٣ ρην δα κιε μει ρϋαι; ο-μει νϋεν κιει
۝٤ να βεν'εντο ρην δα κιε βεν'εν,
۝٥ βιει χεϋ σαλαικα το'κιει ρην το σε
۝٦ νας χεϋ βεν'ενκα ρην λα; λιε νϋεν
۝٧ μαντε φαςιε χϋοινια να λα'νοι.

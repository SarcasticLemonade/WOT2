🙉 كَلَامُ الْجَاهِلِينَ ۝١

۝١ φϋαι σια φα λιηςνω να τεκ σασε ρεκ
۝٢ δοϋ δα γες'εν υκ μιω να φϋογε.

🙉 كَلَامُ الْجَاهِلِينَ ۝٢

۝١ νοιφεκ σε χεϋ νοιφεκ νειλη ω'νω'ε κεν
۝٢ νιεχεϋ νοιφεκ κας οϋ νοιφεκ.

🙉 كَلَامُ الْجَاهِلِينَ ۝٣

۝١ χεϋ μαικα σιο βιαϋγε'ε υι λιε γεϋ
۝٢ να δα φαι κεν δα γεν να δα φοκλη
۝٣ να φα σιο γε'ε; να χεϋ σε'κα
۝٤ λϋω νιος λα πον σιο σεϋ'ε γεν να δα
۝٥ λϋω νιος λα φοι ω'νω'ε πον φα σιο
۝٦ σεϋ'ε; δα δεϋ ιεκ δα τες ρη'νια
۝٧ τε'νω σε κιωκ να δα κει φει φοκ.

🙉 كَلَامُ الْجَاهِلِينَ ۝٤

۝١ φεκνοι'ε ιεςτε να χεϋ χαι νιε δα
۝٢ μα τε: να γαφαιγε'ε ιεςτε
۝٣ γα; να μεςγε'ε ιεςτε μες;
۝٤ φειμοκνια ιεςτε να χεϋ φιος νιε δα
۝٥ μαι τε; ιεςτε λα να χεϋ μαι νιος
۝٦ λα; φε ιεςτε να λειγε'ε.

🙉 كَلَامُ الْجَاهِلِينَ ۝٥

۝١ الدُّنيا لأهلِ السُّكوتِ،
۝٢ إذ لا إثمٌ ولا ألمٌ يقدرُ أن يمسَّ
۝٣ مَن كانَ ساكتًا ولا يتكلَّمُ إلّا إلى
۝٤ الدّارِ أو الْأَرْضِ.

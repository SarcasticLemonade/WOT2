❤️ Сло́во Любъвѐ а҃

а҃ ιες γει λα: ιες λα βενφιε'νω,
в҃ ιες λα γε'νω κεν ιες λα βεϋ'νω.
г҃ λα βενφιε'νω σε χαι να τεκ γε'ε
д҃ υκ βενφιε να δα μιωϋ λε κεν δα λη
є҃ νοι. λα βενφιε'νω μυς γϋεν ιες νιεκ
ѕ҃ ιεν γε υκ βενφιε λη'κα φοκ νεκ.
ꙁ҃ νοιφεκ μυς μαι κεν δαι λα γε'νω να τεκ
и҃ γε εκ φεκ, νοιγε κεν φοκγε,
ѳ҃ νιειγε κεν μεκγε. λα βεϋ'νω νοιφεκ
і҃ μυς δαι να ιεν γε πον τεκ βεν, βιει
аі҃ ιενλη'νια τε'νω σε σος χεϋ νοιφεκ μοκ
ві҃ νϋεν δα'εν μον γε ω'νω πο δα νοιφεκ
гі҃ λη τε μον σος.

❤️ Сло́во Любъвѐ в҃

а҃ λαγε σε γε χεϋ λα κεν λα'ας.
в҃ λαγε νοιφεκνω σε χεϋ λα νοιφεκ κεν να
г҃ νοιφεκ λα'ας.

❤️ Сло́во Любъвѐ г҃

а҃ κοι κεϋ κιε χαι δα φοκλη να σος,
в҃ ο-νοιλη ιαϋ; κεϋ βοιγε κεικα
г҃ σος, ο-τος νιε λιε, καν ο-κας
д҃ να λιε χεϋ ιεκ δα νιετελη τε;
є҃ κεϋ σος μα σος χεϋ κιε χαι, ο-βιαϋ
ѕ҃ τε νιε να λιε, καν ο-φενλη κεν
ꙁ҃ μως οϋ χεϋ ιεκ δα σάνοιλη κεν λιει
и҃ λιε.

❤️ Сло́во Любъвѐ д҃

а҃ και ιεν γε λα νιε φεν να γε δα'νω
в҃ καν φαν λιε'νω, τε νιεσε λα,
г҃ βιει λα βεϋ'νω νεκλαι γε χϋοι κεν γε
д҃ χϋοι σε φεν υκ φαν.

❤️ Сло́во Любъвѐ є҃

а҃ δα βεϋλη σε δα κας: «μιε χαι
в҃ δα ιενλη φεν'ε κεν φαν'ε»,
г҃ κεν δα βεν'εν σε δα ιενλη φεν'ε
д҃ κεν φαν'ε.

❤️ Сло́во Любъвѐ ѕ҃

а҃ να βεν'εντο, ο-φαιλη νιε να
в҃ χαι'ε φαννω κιε'νω, καν φαιλη
г҃ να χαι'ε φαννω να λαγε κεν λϋω
д҃ να λιε λα νιεφαννω.

❤️ Сло́во Любъвѐ ꙁ҃

а҃ ο-λα κιε, ο-λα τεκ γε ω'νω
в҃ εκ φεκ, κεν ο-λα νιεγε'ε.
г҃ να δα λα κιε, ο-σε νοιγε να
д҃ κιε; ο-γαλη πο τεκ λη νεκ;
є҃ ο-ληλη πο τεκ λη βοι; ο-δαι
ѕ҃ να κιε τια δοϋ δα γιωλη; ο-λϋω
ꙁ҃ λα να γε'ε ω'νω, βιει δα δαι
и҃ νοι σε δα δος νοι κεν σα φας φοκ.

❤️ Сло́во Любъвѐ и҃

а҃ ο-μει νϋεν κιει'ε να λα ρην δα κιε
в҃ δος λα; ο-μει νϋεν κιει'ε να ρϋαι
г҃ ρην δα κιε μει ρϋαι; ο-μει νϋεν κιει
д҃ να βεν'εντο ρην δα κιε βεν'εν,
є҃ βιει χεϋ σαλαικα το'κιει ρην το σε
ѕ҃ νας χεϋ βεν'ενκα ρην λα; λιε νϋεν
ꙁ҃ μαντε φαςιε χϋοινια να λα'νοι.

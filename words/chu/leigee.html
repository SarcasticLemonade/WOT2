📖 Св а҃

а҃ λειγε σε νιε χεϋ δεϋ τεκ; λειγε
в҃ σε χεϋ χαι κεν εν να λιε δα δεϋ φα
г҃ να χεϋ λιε δεϋ. χεϋ φαι'ας ζαι χεϋ
д҃ λιε δεϋ κεν εν νιε να λιε δα δεϋ φα
є҃ νιεσε λειγε.

📖 Св в҃

а҃ ο-κει νιε φοκ καν χεϋ εν φοκ.

📖 Св г҃

а҃ κοι νας γοι'ε βιαϋ γα να τια'ε να
в҃ φεινια δοϋ δα γονλη να ζατια κεν
г҃ σοκ, κεν νας νοιφεκ εν χες νοιφεκνω κεϋ
д҃ ιες σιυκ δοϋ δα γονλη να βιωκ; νοιφεκ
є҃ εντε βιε'νια'ε νοιφεκνω να τια'ε
ѕ҃ να λεινια δοϋ δα γονλη να τια'ε
ꙁ҃ να φϋο; νοιφεκ σιατε ληφε'ε κεϋ
и҃ νοιφεκ σε λεινω δοϋ δα γονλη να δα
ѳ҃ σε νον φϋο ϋο μαν. νας νοιφεκ εν νιε
і҃ χες νιω βιωκ να βιωκ, νοιφεκ εν νιε χες
аі҃ νιω μαν νον μαν.
